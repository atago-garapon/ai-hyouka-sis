# 生徒シミュレーター

指導AI（`index.html` の `makeTeacher`）を、指導に反応する仮想の生徒で試すためのツールです。
評価エンジンと指導AIは `index.html` から直接読み込むので、アプリを直せばシミュレーターにもそのまま反映されます。

## 使い方

```
node sim/student_sim.js            # 生徒200人 × 教習10回
node sim/student_sim.js 500 20     # 生徒500人 × 教習20回
```

Node.js があれば追加のインストールは不要です。

## 仕組み

- 評価項目は、本物のコース（c1 / c2）を本物の評価に通して集めたものです（区間・項目・閾値・単位）。
- 生徒は「場面:項目」ごとの能力（0〜1）を持ち、その回の出来を本物のチェックと同じ形（value / threshold / margin / ok）で返します。
- 促し・予告を受けた回は出来が上がり、振り返りや理由の説明を受けると能力が上がります。促しなしで自分でできたときと、促しでできたときでは、定着の量が違います。
- 指導の出し方を5通りで比べます：指導AI ルール / 指導AI Bandit（生徒別）/ 指導AI Bandit（全体のみ）/ 元の指導のまま全部言う / 何も言わない。
- 3タイプの生徒が順番に混ざって入校し、Bandit は前の生徒たちのデータを引き継いで学習していきます。入校順ごとの成績で「データが溜まるほど良くなるか」を見られます。

## 注意

生徒の反応の仕方（`PROFILES` の上達量）はすべて仮置きの値です。
結果は「ルールの違いで何が変わるか」を比べるためのもので、実際の教習効果を示すものではありません。
実車のデータが集まったら、その記録から上達量を推定して置き換えます。

# Safety Gate のチェック

指導AIの出力と音声・画面の間に入る Safety Gate（`index.html` の `makeSafetyGate`、safety_gate_v0.1）を確かめるスクリプトです。

```
node sim/gate_check.js        # 1条件あたり5本（計60本）
node sim/gate_check.js 20     # 1条件あたり20本
```

- アプリの走行シミュレーター（`simulate`）で、ミスあり（標準・要練習・介入あり）× 周りの車なし／ありの走行を作り、評価 → 指導AI → Safety Gate の順に通します。
- 確かめること：危険の状態（安全監視の反応中・直後3秒）に指導が1件も出ていない／高負荷のときに予告・振り返り・前回の課題が出ていない／Gate が止めた指導が指導AIの記録で「言っていない」（`delivered: false`）になっている／Gate の中でエラーが起きたら評価の記録（check）以外が止まる。
- 問題があれば終了コード1で終わります。

生徒シミュレーター（`student_sim.js`）は運転の負荷を再現していないので、Gate は通しません。
